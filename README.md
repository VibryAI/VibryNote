# VibryNote

> AI-first 跨端笔记 / 第二大脑。替代 Evernote、网易云笔记、印象笔记，差异点是 **AI 增强 + 与 AI Agent 互通**。
> 基于 **VibryAI** 基座（多租户 / 认证 / 存储 / AI 能力网关 + SKILL）。

- **域面**：`note.vibry.ai`（Web）；移动 / 桌面端独立
- **平台**：Web · 移动 APP · 桌面（Mac/Win，后做）
- **核心理念**：人记的，AI 和 Agent 能读能用；Agent 产出的，能回落到笔记——让笔记成为你和 Agent 共同喂养的"外脑"。

## 开源策略
- **Web 版（本仓库）＝开源**（`note.vibry.ai` 前端 + 基座对接层）
- **后续客户端（移动 APP / 桌面 Mac·Win）＝私有**（另建私有仓库）
- **基座 VibryAI**＝开源；本产品基于基座的多租户 / 认证 / 存储 / AI 能力网关
